# trail-album - 写真入りKMZをExcelに出力

## 1. 概要

ハイキングで撮った写真の KMZ ファイルと、移動経路の GPX ファイルを読み込む Web アプリです。
写真の撮影場所と移動経路を地理院地図で確かめ、写真と属性（名称・撮影日時・位置）の一覧の
**Excel ファイル**と、**元の画質の写真ファイル**を、好きな名前のフォルダにまとめて保存します。
読み込んだ KMZ・GPX も、それぞれ1つのファイル（2つ以上なら重なりを除いてまとめたもの）にして一緒に保存できます。
画面には「Trail Album」と表示されます。

- 出力したフォルダは、KMZ のままでは中身を見にくい写真データのバックアップとして使います。
- Excel は「目次」、photos フォルダの写真は「元の画質のまま残す本体」という役割分担です。
- KMZ・GPX はいくつでも一緒に読み込めます（同じ写真・経路は重ねません）。
  KMZ は1つのフォルダ・1つの Excel にまとめて保存します。
- GPX は地図で確かめるほか、一緒に保存できます（GPX だけでも保存できます）。
- 処理はすべてブラウザの中で行い、写真を外部へ送信しません。

主な入力は、箕面ハイキングアプリ（minoh-hiking）の写真の「出力」で作った KMZ と、移動経路の GPX です。

## 2. 使い方

1. 「KMZ, GPX ファイルを選ぶ」を押すか、KMZ・GPX ファイルを画面にドラッグ＆ドロップします。
   いくつでも一緒に選べ、後から選んだファイルは今の内容に追加します（同じ写真・経路は重ねて追加しません）。
2. 内容を確かめます。左に KMZ の写真の一覧（すべての KMZ を通した撮影日時の順。No. は保存する写真のファイル名と同じ番号）、右に GPX の経路ごとの内訳と地図が並びます。
   - 写真の右のボタンで、元の写真の拡大表示・縮小版のコピー・元の写真の保存ができます。
     縮小版（長辺 600px）は、一覧の写真・地図の吹き出し・Excel の画像と同じものです。
     コピーは PNG 形式になり（ブラウザの制約）、写真では JPEG より大きくなるため、元の写真ではなく縮小版をコピーします。
     元の画質の写真を文書に入れるときは、「写真を保存」したファイルか、保存した photos フォルダの写真を使ってください。
   - 一覧の写真を押すと、その行に枠を付け、地図でその写真の場所に縮小版の吹き出しを出します
     （地図が見えるところまでスクロールします）。
   - 地図（地理院地図）には、写真の撮影場所と、移動経路（記録地点を線で結んだもの）を表示します。
     読み込んだ地点がすべて収まるように合わせ、右下に「＋」「−」ボタン・ズームレベル（「Z=16.3」）・縮尺の目盛りを出します。
     ズームレベルのボタンを押すと、その左にスライドバーが開き、ズームレベルを 0.1 刻みで変えられます。
     地図を拡大・縮小したときもスライドバーが開き、5 秒操作しないと閉じます（ボタンで開いていても同じです）。
   - 写真の撮影場所のマーカーを押すと、写真の縮小版と No.・名称・撮影日時を吹き出しで出します。
     縮小版を押すと、元の写真を大きく表示します（写真の一覧の「拡大表示」と同じです）。
     あわせて、写真の一覧のその写真の行に枠を付けます（画面はスクロールしません）。
     枠は、ほかの写真を選ぶか、KMZ を読み込み直す・クリアするまで残ります。
   - 地図の右上の「別ウインドウで開く」を押すと、同じ地図（写真の撮影場所・移動経路・凡例）を別のウインドウで大きく表示します。
     画面の地図はそのまま残ります。KMZ・GPX を読み込んだりクリアしたりすると、別ウインドウの地図も合わせて変わります。
     選んだ写真も連動します（別ウインドウでマーカーを押すと一覧に枠が付き、一覧で選んだ写真は別ウインドウにも吹き出しが出ます）。
   - KMZ と GPX が左右に並ぶ画面では、ページを下へスクロールしても、地図は画面の上端で止まって見え続けます
     （写真の一覧をスクロールしながら地図を見られます）。そのため地図の高さはウインドウに収まる高さまでにします。
     上下に並ぶ狭い画面（スマートフォンなど）では、地図は固定しません。
   - 地図を表示している間は、画面の幅いっぱいに広げます。KMZ と GPX の間の境界線をドラッグすると、
     左右の幅を変えられます（ダブルクリックで元の幅に戻ります）。
   - KMZ・GPX それぞれの「クリア」で、読み込んだ KMZ・GPX を画面から外せます（ファイルは消えません）。
   - ページ上部の「すべてクリア」（「1 KMZ, GPX ファイルを選ぶ」の右）で、読み込んだ KMZ・GPX をすべて外し、
     ページを開いたときの状態に戻します（名前・保存するもののチェックも最初に戻ります。保存先フォルダはそのまま残ります）。
3. 保存します。保存の欄で次を決めると、何がどんな名前で保存されるかが「保存される内容」（フォルダ・ファイルの木）に
   すぐ出ます。確かめてから「フォルダに保存」か「ZIP でダウンロード」を押すと、その内容のとおりに保存します。
   - **名前:** 出力フォルダ名・Excel のファイル名・ZIP の名前に使います。最初は読み込んだ内容から作った名前が入っていて、
     自由に書き換えられます。欄の下の「候補」（既定の名前、KML の Document 名、KMZ・GPX のファイル名）を押すと、
     その名前が欄に入ります。「元に戻す」で最初の名前に戻ります。使えない文字は除き、欄の下でそのことを知らせます。
   - **保存するもの:** 「KMZ」にチェックを入れると、写真の一覧(Excel)・写真(photos フォルダ)・KMZ ファイルを、
     「GPX」にチェックを入れると、GPX ファイルを保存します（どちらも最初はチェックが入っています。
     読み込んでいない種類は押せません）。KMZ・GPX は、1つだけ読み込んでいれば元のファイルのまま、
     2つ以上なら同じ写真・経路を除いて1つのファイルにまとめて、出力フォルダの直下に置きます。
   - **フォルダに保存**（Chrome・Edge）: 保存先フォルダの中に出力フォルダを作って保存します。
     同じ名前のフォルダがあるときは上書きせず、「名前 (2)」のように番号を付けます。
     保存先フォルダは「保存先フォルダを指定」で1回選べば覚えておき、次からは選ぶ画面を出さずに保存します
     （「クリア」で忘れさせられます）。保存先フォルダを指定していないと保存できません。
     ブラウザを開き直した後の最初の保存では、書き込みを許可するか確かめられます。
     Chrome 122 以降は、そこで「毎回許可」を選ぶと次からは確かめられません。
   - **ZIP でダウンロード**（すべてのブラウザ）: 出力フォルダと同じ構成の ZIP をダウンロードします。
     ダウンロード先は「ダウンロード」フォルダです（ブラウザの設定でダウンロード先を変えている場合は、その場所になります）。
     展開してから Excel ファイルを開いてください（展開せずに開くと、Excel のリンクから写真を開けません）。

GPX だけを読み込んだときも保存できます（GPX ファイルだけを保存します）。

## 3. 出力

```
20261118_箕面/                       … 出力フォルダ（保存の欄の「名前」）
├─ 20261118_箕面.xlsx                … 写真の一覧（名前と同じ。「KMZ」にチェックを入れたとき）
├─ photos/                           … 「KMZ」にチェックを入れたとき
│  ├─ 001_20261118-1032_箕面大滝.jpg  … 番号_撮影日時(日本時間)_名称（KMZ 内の写真をそのまま保存）
│  └─ ...
├─ 20261118_箕面.kmz                 … 読み込んだ KMZ（名前と同じ。「KMZ」にチェックを入れたとき）
└─ 20261118_箕面.gpx                 … 読み込んだ GPX（名前と同じ。「GPX」にチェックを入れたとき）
```

Excel ファイルの内容:

| シート | 内容 |
|---|---|
| 写真一覧 | No.・サムネイル（長辺 600px の縮小版）・名称・撮影日時（日本時間の日付型）・緯度・経度・地理院地図/Google マップへのリンク・写真ファイルへのリンク・備考（空欄） |
| 情報 | 元の KMZ のファイル名、KML の Document 名、写真の枚数、出力日時、作成アプリ、注意書き |

- サムネイルは「セルに合わせて移動やサイズ変更をする」配置にしています。撮影日時などで並べ替えたり、
  オートフィルターで絞り込んだりすると、画像も行と一緒に動きます（絞り込んだ行の画像は隠れます）。
- ファイル名・フォルダ名では、Windows で使えない文字（`\ / : * ? " < > |`）と制御文字を除きます。
  Excel のリンクが働くよう、`#` と `%` も除きます。名称部分は40文字までにします。
- 写真のファイル名では、名称部分の空白（全角の空白を含む）を `_` に置き換えます（`箕面 大滝` → `箕面_大滝`）。
  名称に元からある `-` はそのまま残します。
  Excel の「名称」列は元の名称（空白を含む）のままです。
- 名前の最初の値は、KML の Document 名（無ければ KMZ のファイル名。GPX だけなら GPX のファイル名）です。
  日付で始まらないときは「最も早い撮影日_」（GPX だけなら最も早い記録日）を前に付けます。
  KMZ・GPX が複数のときは、いちばん早いものの名前を使います。名前は40文字までです。
- 写真の番号は、すべての KMZ を通した撮影日時の順です。
- KMZ・GPX を2つ以上まとめるときは、写真の地点（Placemark）と経路（trkseg）・地点（wpt）を元のファイルからそのまま
  書き写します（標高などの情報も残ります）。まとめた KMZ の写真の名前は `files/photo-001.jpg` のように付け直します。
  まとめたファイルは、Trail Album と minoh-hiking で読み込み直せます。

## 4. ファイル構成

```
trail-album/
├─ public/
│  ├─ index.html
│  ├─ map.html             … 別ウインドウの地図（地図の「別ウインドウで開く」で開くページ）
│  ├─ style.css
│  └─ js/
│     ├─ app.js            … エントリポイント（画面の制御）
│     ├─ constants.js      … 設定値（地図のズームレベルの範囲・色、列の幅、縮小版の大きさなど）
│     ├─ kmz-reader.js     … KMZ の展開・KML の解析
│     ├─ gpx-reader.js     … GPX の解析（経路ごとの移動距離・記録の日時）
│     ├─ xml-utils.js      … XML の読み取り（KML・GPX で共用）
│     ├─ merge.js          … 複数の KMZ・GPX をまとめ、同じ写真・経路を除く
│     ├─ merge-writer.js   … 保存する KMZ・GPX を、それぞれ1つのファイルにまとめる
│     ├─ map-view.js       … 地理院地図の表示（写真の撮影場所・移動経路。画面と別ウインドウで共用）
│     ├─ map-window.js     … 地図を別ウインドウで開き、画面の地図と同じ内容・選んだ写真を知らせ合う
│     ├─ map-window-page.js … 別ウインドウの地図のページ（map.html）のエントリポイント
│     ├─ col-splitter.js   … KMZ と GPX の境界線（左右の幅の変更）
│     ├─ photo-actions.js  … 写真の一覧のボタン（縮小版のコピー・写真の保存）
│     ├─ excel-writer.js   … Excel ファイル（.xlsx）の作成
│     ├─ thumbnail.js      … サムネイルの作成
│     ├─ saver.js          … フォルダへの保存・ZIP の作成
│     └─ naming.js         … フォルダ名・ファイル名の作成と使えない文字の除去
├─ docs/
│  ├─ funcspec-202611.md   … 機能仕様書
│  └─ funcspec-202611.pdf  … 機能仕様書（PDF）
├─ .github/workflows/
│  └─ pages.yml            … public を GitHub Pages に公開する
├─ vercel.json             … outputDirectory を public にする
├─ LICENSE
└─ README.md
```

- Vanilla JavaScript + ES6 モジュール。ビルド工程はありません。
- 外部ライブラリは CDN（jsDelivr）からバージョンを固定し、改ざん検知（SRI）付きで読み込みます。
  - JSZip 3.10.1（KMZ の展開・ZIP の作成）
  - ExcelJS 4.4.0（Excel ファイルの作成）
  - Leaflet 1.9.4（地理院地図の表示）
- ページの通信先は Content-Security-Policy（`connect-src 'self' blob: data:`）でこのサイトの中だけに制限しています。
- 機能の詳しい仕様は、[機能仕様書](docs/funcspec-202611.md) にまとめています。

## 5. 開発・デプロイ

ローカルで確認するときは、`public` フォルダでローカルサーバーを起動します（ES モジュールのため、
index.html を直接開くと動きません。フォルダへの直接保存と縮小版のコピーも https か localhost でのみ使えます）。

```bash
cd public
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

Vercel には、`public` を出力先とする静的サイトとしてデプロイします（ビルドコマンドなし）。

GitHub Pages（https://sato4app.github.io/trail-album/）には、`main` に push するたびに
GitHub Actions（`.github/workflows/pages.yml`）が `public` フォルダを公開します。
リポジトリの Settings → Pages → Source は「GitHub Actions」にしておきます
（「Deploy from a branch」のままだと、ルートに index.html が無いため README.md が表示されます）。
